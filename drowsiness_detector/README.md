# Drowsiness Detector (laptop side)

Setup, run instructions, detection thresholds, tuning and the Android app are
documented in the [main README](../README.md).

Quick start, from this folder:

```powershell
..\.venv\Scripts\python.exe main.py
```

Keys: `Q` quit · `C` calibrate · `I` toggle IR simulation. All settings live in
`config.py`.
